# CFMeeting Video Platform မိတ်ဆက်နှင့် လုပ်ဆောင်ချက်များ (Overview & Features)

**CFMeeting** သည် Cloudflare ၏ နောက်ဆုံးပေါ် နည်းပညာများဖြစ်သော **Cloudflare Workers (Edge Computing)**၊ **Cloudflare RealtimeKit (WebRTC)** နှင့် **Cloudflare R2 (Object Storage)** တို့ကို ပေါင်းစပ်၍ တည်ဆောက်ထားသည့် **၁၀၀% Serverless (သီးခြား Server / VPS ဝယ်စရာမလိုသော)** ခေတ်မီ Open-Source Video Conference & Webinar Platform ဖြစ်ပါသည်။

* **တရားဝင် Live လိပ်စာ:** [https://cfmeeting.uzinlay85.workers.dev](https://cfmeeting.uzinlay85.workers.dev)
* **GitHub Repository:** [uzinlay85/zin-cfmeeting](https://github.com/uzinlay85/zin-cfmeeting)

---

## ၁။ အဓိက ထူးခြားချက်များနှင့် အကျိုးကျေးဇူးများ (Key Benefits)

| အချက်အလက် | အခြား Zoom / Google Meet / VPS များ | ကျွန်ုပ်တို့၏ CFMeeting |
| :--- | :--- | :--- |
| **Server ကုန်ကျစရိတ်** | လစဉ် VPS ($10 - $50+) သို့မဟုတ် Zoom Pro ($15+/လ) ပေးဆောင်ရခြင်း | **Cloudflare Free Tier ကြောင့် Server စရိတ် လုံးဝ (Zero Cost) ကုန်ကျမှု မရှိခြင်း** |
| **Server ပြုပြင်ထိန်းသိမ်းမှု** | Linux OS update, Nginx, SSL, Database maintenance ကိုယ်တိုင် လုပ်ဆောင်ရခြင်း | **Serverless ဖြစ်၍ ပြုပြင်ထိန်းသိမ်းစရာမလို (Zero Maintenance)** |
| **ကွန်ရက်မြန်နှုန်း (Latency)** | သီးသန့် VPS တည်ရှိရာ နိုင်ငံတစ်ခုတည်းမှသာ ဒေတာပို့ဆောင်ခြင်း | **Cloudflare ၏ ကမ္ဘာတစ်ဝှမ်း မြို့ပေါင်း ၃၀၀+ Data Centers များမှ အနီးဆုံးလမ်းကြောင်းဖြင့် အမြန်ဆုံး ချိတ်ဆက်ပေးခြင်း** |
| **လုံခြုံရေး & Privacy** | Third-party Server များပေါ်တွင် ဒေတာများ ဖြတ်သန်းခြင်း | **မိမိကိုယ်ပိုင် Cloudflare Account တွင်သာ လျှို့ဝှက်ချက်များနှင့် ဗီဒီယိုများ စိတ်ချစွာ သိမ်းဆည်းခြင်း** |
| **တပ်ဆင်ရလွယ်ကူမှု** | ဆော့ဖ်ဝဲလ် သီးသန့် install မဖြစ်မနေ လုပ်ဆောင်ရခြင်း | **Browser Link တစ်ခုတည်းဖြင့် ဖုန်း/ကွန်ပျူတာ မည်သည့်စက်တွင်မဆို တန်းတက်နိုင်ခြင်း** |

## ၂။ ပါဝင်သော လုပ်ဆောင်ချက်များ အပြည့်အစုံ (Features & Capabilities)

### (၁) အစည်းအဝေး အမျိုးအစား (၂) မျိုး ရွေးချယ်နိုင်ခြင်း
* **Conference (အဖွဲ့လိုက် အစည်းအဝေး):**
  * တက်ရောက်သူ အားလုံးက မိုက်ခရိုဖုန်း၊ ကင်မရာ ဖွင့်နိုင်ပြီး Screen Share ပြုလုပ်နိုင်ပါသည်။
  * ရုံးတွင်း အဖွဲ့လိုက် ဆွေးနွေးပွဲများ၊ မိသားစု/မိတ်ဆွေများ စကားပြောဆိုခြင်းနှင့် စာသင်ဝိုင်းများအတွက် အထူးသင့်တော်ပါသည်။
* **Webinar (ဟောပြောပွဲ / သင်တန်းကြီးများ):**
  * Host (ဟောပြောသူ) သာ စင်မြင့်ပေါ်တွင် ကင်မရာ/မိုက် ဖွင့်ခွင့်ရှိပြီး တက်ရောက်သူ ပရိသတ်များသည် ကြည့်ရှုနားထောင်သူ (Viewers) အဖြစ်သာ တက်ရောက်ရပါသည်။
  * ပရိသတ်မှ မေးခွန်းမေးလိုပါက **"Request to speak" (လက်ထောင်ခွင့်တောင်း)** နိုင်ပြီး Host က ခွင့်ပြုပါက စင်မြင့်ပေါ်သို့ တက်ရောက်စကားပြောနိုင်ပါသည်။

---

### (၂) Cloud Recording စနစ် (Cloudflare R2 Storage ပေါင်းစပ်မှု)
* **တိုက်ရိုက် Cloud ပေါ်သို့ မှတ်တမ်းတင်ခြင်း:**
  * ကွန်ပျူတာ၏ Hard disk နေရာမစားဘဲ Cloudflare ၏ R2 Storage (`cfmeeting-records`) ထဲသို့ အရည်အသွေးမြင့် **`.mp4`** ဗီဒီယိုဖိုင်အဖြစ် တိုက်ရိုက် သိမ်းဆည်းပေးပါသည်။
* **လွယ်ကူစွာ စတင်နိုင်ခြင်း:**
  * Host အနေဖြင့် မီနူးထဲရှိ **"Start recording"** ခလုတ်တစ်ချက် နှိပ်လိုက်ရုံဖြင့် Recording စတင်ပြီး ထိပ်တွင် အနီရောင် Indicator ပြသပေးပါသည်။
  * အစည်းအဝေးပြီးဆုံးပါက Cloudflare Dashboard မှ အချိန်မရွေး ပြန်လည် Download ပြုလုပ်နိုင်ပါသည်။

---

### (၃) လုံခြုံရေးဆိုင်ရာ ကာကွယ်မှုစနစ် (Security & Access Control)
* **Access Code Protection (စတင်ဖွင့်လှစ်ခွင့် ကာကွယ်ခြင်း):**
  * Server ပိုင်ရှင်အနေဖြင့် မိမိစိတ်ကြိုက် လျှို့ဝှက် Access Code (Passcode) သတ်မှတ်ထားနိုင်ပြီး ခွင့်ပြုချက်မရှိသော လူစိမ်းများက သင်၏ Worker URL ပေါ်တွင် Meeting များ အလဟဿ လှမ်းဖွင့်ကာ Quota ဖြုန်းတီးခြင်းကို အပြည့်အဝ တားဆီးထားနိုင်ပါသည်။
* **Host Key Secret (အကြီးအကဲ အခွင့်အရေး ကာကွယ်ခြင်း):**
  * အစည်းအဝေးကို စတင်ဖန်တီးသူ (Host) အတွက် လျှို့ဝှက် Host Key တစ်ခု ထုတ်ပေးထားပြီး အခြားသူများက Host အခွင့်အရေးကို လုယူ၍ မရနိုင်ပါ။
* **ဧည့်သည်များ ဝင်ရောက်ရလွယ်ကူခြင်း:**
  * ဖိတ်ကြားခံရသော ဧည့်သည်များသည် Access Code မလိုဘဲ သင်ပေးပို့လိုက်သော Meeting Link ဖြင့် ကလစ်တစ်ချက်နှိပ်ရုံဖြင့် လွတ်လပ်စွာ ဝင်ရောက်နိုင်ပါသည်။

---

### (၄) အစည်းအဝေးခန်းတွင်း စွမ်းဆောင်ချက်များ (In-Meeting Controls)
* **Screen Sharing (စခရင် မျှဝေခြင်း):** ကွန်ပျူတာစခရင်၊ PowerPoint Slides များ၊ စာရွက်စာတမ်းများကို အခြားသူများထံ ချက်ချင်း Share ပြသနိုင်ခြင်း။
* **Real-time Chat (စာတိုပေးပို့ခြင်း):** အစည်းအဝေးခန်းတွင်း စာသားများ၊ Link များနှင့် ဖိုင်များကို ပေးပို့နိုင်ခြင်း။
* **Polls (မဲခွဲဆုံးဖြတ်ခြင်း / စစ်တမ်းကောက်ယူခြင်း):** မေးခွန်းထုတ်၍ တက်ရောက်သူများ၏ သဘောထားမဲများကို ကောက်ယူနိုင်ခြင်း။
* **Mute All (အားလုံး မိုက်ပိတ်ခြင်း):** ဆူညံသံများ မထွက်စေရန် Host က တက်ရောက်သူ အားလုံး၏ မိုက်ကို တစ်ပြိုင်နက် ပိတ်ပစ်နိုင်ခြင်း။
* **Breakout Rooms (အခန်းခွဲ ဆွေးနွေးခြင်း):** အဖွဲ့ငယ်များ သီးခြားခွဲ၍ ဆွေးနွေးရန် အခန်းခွဲငယ်များ အလိုအလျောက် သို့မဟုတ် ကိုယ်တိုင် ရွေးချယ်ဖန်တီးပေးနိုင်ခြင်း။
* **Audio & Video Settings:** မိမိအသုံးပြုမည့် Microphone, Camera, Speaker များကို စိတ်ကြိုက် ရွေးချယ်စမ်းသပ်နိုင်ခြင်း။
* **Full Screen Mode:** အာရုံစူးစိုက်မှု ကောင်းမွန်စေရန် မျက်နှာပြင် အပြည့် ချဲ့ကြည့်နိုင်ခြင်း။

---

### (၅) စက်ပစ္စည်းမျိုးစုံတွင် အသုံးပြုနိုင်ခြင်း (Multi-Platform Support)
* **Web Browser (Chrome, Safari, Firefox, Edge):**
  * မည်သည့် Software မှ သွင်းစရာမလိုဘဲ တိုက်ရိုက် သုံးနိုင်ပါသည်။
* **PWA (Progressive Web App):**
  * ဖုန်း Browser တွင် **"Add to Home Screen"** ပြုလုပ်လိုက်ပါက ဖုန်းဆော့ဖ်ဝဲလ်တစ်ခုသဖွယ် App Icon ဖြင့် ပေါ်နေမည် ဖြစ်ပါသည်။
* **Android APK:**
  * Capacitor နည်းပညာဖြင့် Android ဖုန်းများအတွက် သီးသန့် App (`.apk`) အဖြစ် တည်ဆောက်နိုင်ပါသည်။
* **Desktop App (Windows / Mac):**
  * Electron နည်းပညာဖြင့် ကွန်ပျူတာပေါ်တွင် တပ်ဆင်အသုံးပြုနိုင်သော Windows Installer (`.exe`) အဖြစ် အလွယ်တကူ ထုတ်ယူနိုင်ပါသည်။

## ၃။ အသုံးပြုနည်း အဆင့်ဆင့် လမ်းညွှန်

```
[အဆင့် ၁: Start Meeting]
       │ Host က ဝဘ်ဆိုက်သို့သွားပြီး နာမည် (နှင့် သတ်မှတ်ထားပါက Access Code) ရိုက်ကာ အစည်းအဝေး စတင်သည်။
       ▼
[အဆင့် ၂: Invite Guests]
       │ အပေါ်ဘားရှိ "Invite" ခလုတ်ကို နှိပ်၍ Link ကို ကူးယူကာ Viber, Telegram, Messenger စသည်တို့မှတစ်ဆင့် ဖိတ်ကြားသည်။
       ▼
[အဆင့် ၃: Cloud Recording]
       │ အစည်းအဝေးကို မှတ်တမ်းတင်လိုပါက "More (...)" -> "Start recording" ကို နှိပ်သည်။
       ▼
[အဆင့် ၄: Meeting ပြီးဆုံးခြင်း]
       │ အစည်းအဝေး ပြီးဆုံးပါက "Leave" -> "End meeting for all" နှိပ်သည်။
       ▼
[အဆင့် ၅: ဗီဒီယို Download ရယူခြင်း]
         Cloudflare R2 Bucket ထဲမှ .mp4 ဖိုင်ကို အချိန်မရွေး ပြန်လည်ဒေါင်းလုဒ်ဆွဲယူသည်။
```

## ၄။ အချုပ်သုံးသပ်ချက်

ယခု ကျွန်ုပ်တို့ တည်ဆောက်ထားသော **CFMeeting** သည် သာမန် ဝဘ်ဆိုက်တစ်ခု မဟုတ်ဘဲ:

1. **Google Meet / Zoom ကဲ့သို့ အဆင့်မြင့် အစည်းအဝေးများ ပြုလုပ်နိုင်ခြင်း၊**
2. **Server စရိတ် လုံးဝ မကုန်ဘဲ Cloudflare ၏ အဆင့်မြင့် Infrastructure ပေါ်တွင် အခမဲ့ လည်ပတ်နိုင်ခြင်း၊**
3. **Cloud Recording စနစ်ဖြင့် အစည်းအဝေး ဗီဒီယိုများကို Cloud ပေါ်သို့ အလိုအလျောက် သိမ်းဆည်းပေးနိုင်ခြင်း၊**
4. **Passcode / Access Code ဖြင့် မလိုလားအပ်သော အသုံးပြုမှုများကို လုံခြုံစွာ ကာကွယ်ထားနိုင်ခြင်း**

စသည့် စွမ်းဆောင်ရည်မြင့် အကျိုးကျေးဇူးများ အားလုံး ပါဝင်သော **Enterprise-grade Serverless Video Platform** ဖြစ်ပါသည်။
